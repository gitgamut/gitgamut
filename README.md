### 🚀 Projects

**🌤️ [TheWeatherDB](https://www.theweatherdb.com)** — Weather comparison made simple.

I created and maintain TheWeatherDB, a full-stack weather platform with visitors from 150+ countries. It helps people compare weather across cities to make better decisions about travel, relocation, and outdoor activities.

Features include:
- Interactive maps and charts comparing weather across multiple cities.
- Side-by-side forecasts and historical climate comparisons.
- Automated weather data ingestion and processing.
- An AI-powered weather assistant that suggests activities suitable for current local weather.

**Tech:** React, TypeScript, Python, Node.js, MongoDB, D3.js, AWS.

**📖 [bible-rag-builder-oss](https://github.com/gitgamut/bible-rag-builder-oss)** — Open-source RAG pipeline for weather-inspired scripture reflections.

An open-source project that uses generative AI to offer each user an encouraging thought inspired by their live, local weather. It combines weather data, scripture, and AI to create personalized reflections that provide inspiration, spiritual guidance, and a moment of perspective.

- Processes and organizes 31,000+ Bible verses into meaningful passages.
- Uses historical weather percentiles to identify relevant themes.
- Retrieves passages based on local weather conditions.
- Generates personalized, encouraging reflections using LLMs while preserving accurate scripture quotations.
- Designed with reusable pipeline stages to support additional texts and traditions.
- **Now available as a free, public API on [RapidAPI — Weather Reflections](https://rapidapi.com/junctiv-junctiv-default/api/weather-reflections).**

**Tech:** Python, AWS Bedrock, RAG, LLMs.
